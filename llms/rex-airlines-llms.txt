# Rex Airlines

> Rex Airlines (Regional Express, IATA ZL / ICAO RXA) is Australia's second-largest regional carrier, headquartered in Mascot, New South Wales, flying a Saab 340 fleet to roughly 45 regional destinations across every Australian state. Rex is the inventory owner, not an intermediary: it runs Sabre's SabreSonic passenger service suite for inventory, reservations, ticketing, ancillaries and check-in, sells direct through its own ASP.NET booking engine, and reaches the trade through a web-only Travel Agent portal gated on an IATA, DAPA or TIDS accreditation number.

> API posture: **there is no public API.** Rex publishes no developer portal, no API documentation, no OpenAPI or other machine-readable contract, and makes no reference to IATA NDC anywhere on rex.com.au. `developer.`, `developers.`, `api.`, `docs.`, `status.` and `trust.` subdomains of rex.com.au do not resolve. `/openapi.json`, `/swagger.json`, `/api-docs`, `/.well-known/security.txt`, `/llms.txt`, `/robots.txt` and `/sitemap.xml` all return 404 on www.rex.com.au. The only published trace of a programmatic interface is a checkbox labelled "Request API Access" (`ContentPlaceHolder1_cbAPI`) on the travel agent registration form — no specification, no name, no base URL, no terms, no pricing, and gated behind a mandatory travel-agency accreditation.

## APIs

None. No first-party API is documented or advertised by Rex Airlines.

## Access

- [Travel Agent Portal](https://www.rex.com.au/TravelAgent/Index.aspx): accredited-agent login. Identity is an IATA, DAPA or TIDS number that "cannot be changed for this registration in the future".
- [Travel Agent Registration](https://www.rex.com.au/TravelAgent/agentregistration.aspx): the only route to programmatic access. Requires ABN, Australian travel agency licence number, IATA/DAPA/TIDS accreditation, agency bank/BSB details and an RCTI/GST agreement. Carries the "Request API Access" checkbox.
- [Travel Agent FAQ](https://www.rex.com.au/TravelAgent/faq.aspx): agent operating rules. Statements are kept on the Rex server for two months and downloadable for the last four months.

## Third-party Rex data (NOT published by Rex)

Rex schedule, status and metadata are resold by aviation data aggregators. These are third-party observations of Rex operations, not a Rex interface, and carry no Rex contract:

- Aviation Edge timetable/flight-tracker data filtered on `airline_iata=ZL`
- Airhex airline metadata and logo API
- Flightera flight status and fleet pages

Rex seat inventory itself reaches agencies through Sabre's SabreSonic host (GDS-intermediated). Rex publishes no NDC endpoint and claims no NDC certification.
